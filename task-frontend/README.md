# task-frontend

React + TypeScript + Vite + react-router.

```
npm install     # creates node_modules and package-lock.json
npm run dev     # http://localhost:5173
npm run build   # creates dist/
npm run lint
```

Login: any email + password of 4+ characters.
Data lives in localStorage (src/api.ts). Replace those functions with fetch() calls to use a real backend.
